# Retro Media — Мультимедийная SPA-платформа с ретро-интерфейсом

Полнофункциональное Single Page Application (SPA), воссоздающее интерфейс легендарной соцсети начала 2010-х годов. Проект успешно мигрирован с императивного подхода (Vanilla JS) на декларативную компонентную архитектуру React + TypeScript и интегрирован с облачным бэкендом.

[👉 Ссылка на живой деплой ](https://retro-media-react-ts.vercel.app/)

---

## 🚀 Функционал

- **Архитектура:** Сетевые интеграции и главный функционал приложения написаны на ванильном синтаксисе и библиотеках, являющихся стандартом индустрии (React Query/Tanstack Query, Zustand, React Router DOM), без использования SDK 
- **Real-time Лента (WebSockets):** Лента постов с возможностью публикации новых, обновляется автоматически через Websockets
- **Аудиоплеер:** MP3-плеер на HTML5 Audio API. Воспроизведение не прерывается при переходе между страницами. В панели управления реализована динамическая строка состояния (текущее время воспроизведения, интерактивная полоска хронометража и громкости), данная механика реализована благодаря Zustand
- **Модуль Граффити:** Кастомный графический редактор на HTML5 Canvas API. Есть возможность настройки цвета, толщины и интенсивности линий, готовые изображения сжимаются при сохранении и публикуются на стене
- **Бэкенд:** База данных проекта (таблицы, файловые хранилища) расположена на Supabase. Спроектирована структура таблиц и бакетов, настроены права доступа
- **Клиентская Авторизация:** Авторизация реализована через сохранение данных пользователя в localStorage, при этом фотография, загружаемая пользователем, сжимается для экономии места на сервере, ссылка на фото также сохраняется в localStorage
- **UI/UX:** Адаптивная кроссбраузерная верстка с использованием SCSS Modules. Реализована валидация (ограничение длины строк, запрет отправки пустых строк и защита от загрузки посторонних файлов при авторизации). Для индикации загрузки реализованы лоадеры и скелетоны, также реализована обработка сценариев ошибки загрузки данных (вместо данных появляется заглушка с кнопкой повторного запроса)
- **Оптимизация производительности & Ресайз:** Написан алгоритм предварительного сжатия и форматирования загружаемых аватарок через скрытый Canvas-контекст на клиенте ради экономии места  в хранилище сервера. Оптимизированы рендеры компонентов при обновлении таймеров плеера. Содержимое страниц кэшируется через Tanstack Query для минимизации повторных загрузок.
- **Обработка ошибок:** Реализована обработка критических ошибок сети при интеграции с Supabase. При падении сетевых запросов приложение не "падает", а перехватывает исключения в блоках try/catch, отображая интерактивные плашки уведомлений с возможностью ручной инициализации повторных запросов (refetch).
- **Касчество кода:** Настроены pre-commit хуки через Husky и lint-staged. Код автоматически проходит проверку линтером перед каждым коммитом, что исключает попадание синтаксических ошибок в удаленный репозиторий.
- **Файловая структура проекта:** Структура файлов и блоки кода разделены на логические переиспользуемые модули и утилиты согласно методологии FSD.

## 🛠 Технологический стек (Tech Stack)

- **Core:** React 19, TypeScript, Vite.
- **State & Routing:** Zustand, React Router DOM.
- **Backend & API:** Supabase (PostgreSQL), Tanstack Query, WebSockets (Native Protocol).
- **Browser API:** HTML5 Canvas API, HTML5 Audio API, LocalStorage.
- **Styles & DevTools:** SCSS Modules, Git/GitHub (GitHub Pages).
- **CI/CD & Quality Control:** Husky, lint-staged, ESLint
- **Testing:** Vitest


## 🐳 Развертывание и запуск в Docker (Production)

### 📋 Предварительные требования:
Наличие установленного Docker Desktop на вашем ПК **[Docker Desktop](https://docker.com)**.

### 🛠️ Инструкция по развертыванию:

1. **Клонирование репозитория:**
   git clone https://github.com/aushfoish/retro-media-react-ts
   
2. **Переход в директорию проекта:**
   cd retro-media-react-ts
   
3. **Сборка:**
   docker build -t retro-media-react-ts .
   
4. **Запуск:**
   docker run -d -p 8080:80 retro-media-react-ts
   

После запуска приложение будет доступно по адресу **http://localhost:8080**
