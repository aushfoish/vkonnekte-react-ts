## Архитектура

- **Стек:** Javascript, HTML5, React 19, Typescript, REST API/React Tanstack Query, Zustand, React Router DOM, Zod-validation, Supabase (таблицы и бакеты, без sdk)

## 🚀 Функционал

- **Система аккаунтов:** Полноценная система аккаунтов с навигацией между разными пользователями (данные анкеты и стены отображаются по запросу через ID), возможность заполнить анкету и загрузить фото (jpeg only)
- **Лента постов:** У каждого аккаунта полноценная стена с возможностью писать посты, оставлять комментарии и рисовать граффити
- **Аудиоплеер:** MP3-плеер на HTML5 Audio API. Воспроизведение не прерывается при переходе между страницами. В панели управления реализована динамическая строка состояния (текущее время воспроизведения, интерактивная полоска хронометража и громкости), данная механика реализована благодаря Zustand
- **Модуль Граффити:** Кастомный графический редактор на HTML5 Canvas API. Есть возможность настройки цвета, толщины и интенсивности линий, готовые изображения сжимаются при сохранении и публикуются на стене
- **Авторизация:** Полноценная авторизация с логином и паролем через JWT-токены с проверкой "свежести" и обновлением 
- **UI/UX:** Адаптивная кроссбраузерная верстка с использованием SCSS Modules. Реализована валидация в форме постинга и авторизации (ограничение длины строки, запрет отправки пустых строк и защита от загрузки посторонних файлов на фронтенде и в базе данных). Индикация загрузки через лоадеры и скелетоны.
- **Оптимизация производительности & Ресайз:** При загрузке фото в профиль и отправке граффити файлы сжимаются с сохранением соотношения сторон для экономии места и повышения производительности сайта.
- **Обработка ошибок:** при падении сетевых запросов появляется явная индикация ошибок и возможность отправить повторный запрос
- **Касчество кода:** Настроены pre-commit хуки через Husky и lint-staged. Код автоматически проходит проверку линтером перед каждым коммитом, что исключает попадание синтаксических ошибок в репозиторий.
- **Файловая структура проекта:** архитектура файлов разделена на FSD для удобства масштабируемости и поддержки при росте функционала

## 🛠 Технологический стек (Tech Stack)

- **Core:** React 19, TypeScript, Vite.
- **State & Routing:** Zustand, React Router DOM.
- **Backend & API:** Supabase (PostgreSQL), Tanstack Query, WebSockets (Native Protocol).
- **Browser API:** HTML5 Canvas API, HTML5 Audio API, LocalStorage.
- **Styles & DevTools:** SCSS Modules, Git/GitHub (GitHub Pages).
- **CI/CD & Quality Control:** Husky, lint-staged, ESLint
- **Testing:** Vitest


## 🐳 Развертывание и запуск в Docker (Production)

### 📋 Предварительные требования:
Наличие установленного Docker Desktop на вашем ПК **[Docker Desktop](https://docker.com)**.

### 🛠️ Инструкция по развертыванию:

1. **Клонирование репозитория:**
   git clone https://github.com/aushfoish/vkonnekte-react-ts
   
2. **Переход в директорию проекта:**
   cd vkonnekte-react-ts
   
3. **Сборка:**
   docker build -t vkonnekte-react-ts .
   
4. **Запуск:**
   docker run -d -p 8080:80 vkonnekte-react-ts
   

После запуска приложение будет доступно по адресу **http://localhost:8080**
